## KEY ARCHITECTURAL PATTERNS:

1. **Ambient Session**: Uses contextvars for thread-safe session management
   - Avoids passing session through multiple layers
   - Used in: PersistenceTransform, ChunkPersistenceTransform, FTSManager, etc.

2. **Lazy Initialization**: 
   - _embed_model, _vector_store_manager in IngestPipeline
   - _index in VectorStoreManager, VectorSearch
   - Retrievers in SearchService

3. **Transform Chain**: LlamaIndex IngestionPipeline orchestrates multiple transforms
   - Each transform is stateless (mostly)
   - Transforms modify nodes in-place and pass through

4. **Dual Persistence**:
   - SQLAlchemy for documents/metadata (SQLite)
   - LlamaIndex StorageContext for vector store (JSON files)
   - FTS5 virtual tables integrated with SQLite

5. **Metadata-Driven Filtering**:
   - source_doc_id format: "{dataset_name}:{path}"
   - Used for dataset filtering in vector search
